[TECH STACK SUMMARY]
- Frontend: React (v18), Vite (Port 5173/5175), Web Speech API (Browser STT), Web Audio API, Socket.IO Client, Axios
- Backend: Node.js, Express, Socket.IO Server (Port 5001 - resolved macOS port 5000 AirPlay conflict), MongoDB (In-memory fallback for local dev), JWT Auth
- AI Integration: Google Gemini AI API (Script generation, Stage Co-Pilot, Announcement suggestions)

[COMPLETED STAGES & FEATURE MATRIX]
1. STAGE 1: Anchor Teleprompter & Live Speech Follower
   - High-contrast, stage-ready Teleprompter UI.
   - Horizontal mirror mode (for physical glass teleprompters).
   - Auto-scroll with variable speed controls and dynamic font sizes.
   - Pronunciation guide for speaker names & terms.
   - Urgent Flash Banner & Web Audio chime alert system.
   - Browser Web Speech API for real-time speech tracking & teleprompter auto-follow.

2. STAGE 2: Organizer War Room & AI Co-Pilot
   - Real-time Organizer War Room control dashboard.
   - Cascading Delay Engine: automatically recalculates downstream session start times across tracks when delays occur.
   - AI Stage Co-Pilot powered by Gemini API for live delay mitigation and announcements.
   - Real-time multi-user WebSocket synchronization via Socket.IO.

3. STAGE 3: Multi-Track Support & QA Integration
   - Support for multiple concurrent tracks (Track A — Main Stage, Track B — Workshop Hall, Track C — Networking).
   - Track-isolated delay management (adjust delays on a specific track without affecting unrelated stages).
   - Anchor Station track selector.
   - 13/13 automated integration tests passing cleanly.
